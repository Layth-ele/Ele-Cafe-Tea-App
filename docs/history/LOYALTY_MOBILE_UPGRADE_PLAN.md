# Loyalty Mobile App Upgrade Plan

## Overview
This document outlines a comprehensive plan to upgrade the Ele Café e-commerce web app into a full-featured loyalty mobile app with Clover POS and QR code integration.

---

## 1. Project Goals
- Refactor the current web app to a cross-platform mobile app (iOS/Android)
- Implement a robust loyalty program (points, rewards, redemption)
- Integrate with Clover POS for in-store loyalty and payment
- Add QR code generation and scanning for user identification and rewards
- Maintain or improve current e-commerce features

## 2. Technology Stack
- **Mobile Framework:** React Native (preferred for code reuse), or Flutter
- **Backend:** Firebase (Firestore, Auth, Functions, Storage)
- **Clover Integration:** Clover REST API/SDK
- **QR Code:** react-native-qrcode-svg, react-native-camera (or Expo equivalents)
- **Other:** React Query, Zod, Context API, Sonner (or mobile alternative)

### 3.3. Loyalty Program Implementation
- Design loyalty schema (points, rewards, tiers)

- Add admin controls for managing rewards

### 3.4. Clover POS Integration
- Register for Clover developer account
- Review Clover API docs for loyalty and payment endpoints
- Implement OAuth and secure API calls
- Sync user points/redemptions with Clover
- Test in-store scenarios (earn/redeem at POS)

### 3.5. QR Code Features
- Generate QR code for user ID or reward
- Add QR code scanner for POS and in-app use
- Link QR scans to loyalty actions (earn/redeem)

### 3.6. Testing & QA
- Manual and automated testing on iOS/Android
- Test all loyalty, QR, and Clover flows
- User acceptance testing

### 3.7. Deployment
